# V0.13 Parser Assumptions, Limits and Known Issues

## 解析規則

- 優先辨識「有效期限、使用期限、活動期間、兌換期限、截止、至」附近的日期。
- 支援 `YYYY/MM/DD`、`YYYY-MM-DD`、`YYYY.MM.DD`、中文年月日及民國年。
- 缺少年份的 `MM/DD` 不猜年份，必須人工選擇。
- 多個日期無明確上下文時標示需要確認，並保留其他可能日期。
- 分類只能建議既有九種分類。

## 安全上限

- 圖片或 PDF：30 MB。
- PDF：30 頁。
- PDF 頁面 OCR 渲染寬度：3000 px，高度依比例計算。
- 上限是第一階段的記憶體與等待時間保護值，需依 Founder 實機結果再調整。

## 已知限制

1. 有 `ITEM` 商品編號的多欄型錄會依文字座標切成多筆候選；沒有商品編號、區塊互相重疊或嚴重模糊時，仍可能需要人工拆頁。
2. 低解析度、反光、手寫字、藝術字與複雜底圖會降低 OCR 品質。
3. 第一次使用中文 OCR 時，實際延遲與 APK 大小會因 ML Kit 原生模型及裝置而異。
4. 加密、損壞或 Android PDF Renderer 不支援的 PDF 會被拒絕。
5. 取消是頁面邊界的合作式取消；正在執行的單頁原生 OCR 完成後才會停止。
6. 重複判斷採名稱、品牌與到期日的保守比對，可能漏掉寫法不同的同一優惠。
7. 本版沒有雲端準確率統計；所有成功率只能用本機測試樣本計算，不得推估。

## 100% 驗收口徑

- 只計算有人工標註正確答案的測試樣本。
- 同時檢查候選數量、優惠名稱、到期日與折扣內容。
- 不得只用「有產生候選」或主觀目測宣稱達標。
- 目前隨附 9 頁 Costco 型錄的可核對基準為 122 個不重複 `ITEM`；未完成 122 筆逐項實機比對前，不得宣稱該 PDF 達 100%。
