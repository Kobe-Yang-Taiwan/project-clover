# Project Clover V0.13 Release Notes

版本：`0.13.1（Build 14）`

## V0.13.1 辨識完整率修正

- PDF 頁面 OCR 寬度由 1600 px 提升至 3000 px，改善多欄型錄的小字辨識。
- 保留 OCR 文字行的版面座標，以商品編號與相對位置切割同頁多筆優惠。
- 同頁活動期間會套用到該頁分割出的商品候選。
- 排除手機狀態列時間、網路狀態、頁碼與型錄固定標題，避免誤當優惠名稱。
- 新增型錄候選完整率 Gate：有標註答案的自動測試必須達 100%。
- 隨附 9 頁測試型錄的文字層共有 122 個不重複 `ITEM`，實機驗收必須逐項核對候選數、名稱、到期日與優惠值。
- 100% 門檻只代表已人工標註並完成核對的樣本；未知版型仍須人工確認，不宣稱通用辨識率為 100%。

## 本版重點

- 「新增優惠」現在可選手動輸入、匯入圖片或匯入 PDF。
- 圖片與 PDF 都在手機內辨識，不上傳檔案或文字。
- 辨識結果不會直接存檔；名稱與到期日必須由使用者確認。
- PDF 可逐頁處理、取消、挑選、編輯及批次建立優惠。
- 日期解析支援西元、民國年、中文年月日與日期區間。
- 疑似重複只取消預設勾選並提醒，不會覆蓋舊資料。

## 安全限制

- 單一檔案最多 30 MB，PDF 最多 30 頁。
- PDF 頁面暫時轉成圖片供 OCR 使用，結束或取消後刪除。
- 優惠永久資料只包含使用者確認後的既有欄位，不保存來源圖片或 PDF。
- 診斷匯出不含 OCR 文字、優惠名稱、品牌、備註或來源檔內容。

## 仍未包含

相機、Android 分享目標、條碼／QR Code、外部 AI、雲端同步、iOS、遊戲化與 Google Play 發布。
