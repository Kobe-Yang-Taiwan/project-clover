## Founder Local Image POC decision — 2026-08-18

The standard/free image import path must not depend on Gemini, OpenAI or another
paid cloud model. It uses local multi-signal region proposal, region-by-region
OCR and one-tap missing-region recovery. The target KPI is No-Typing Import Rate
>= 95%, not perfect autonomous recognition.

Existing cloud/provider/proxy/privacy code remains dormant optional research
infrastructure. Do not delete it, deploy new infrastructure or invoke it from the
normal promotional-image path. Native-text PDF remains local and unchanged.

POC gates:

- FamilyMart automatic correct regions >= 7/8;
- PX Mart automatic correct regions >= 11/12;
- approximately one tap recovers a missed product without normal text entry;
- zero cloud requests and approximately zero Founder inference cost;
- no false-candidate explosion or major cross-product contamination.

Conditional performance (FamilyMart 5–6/8 or PX Mart 8–10/12) permits one
controlled Region Proposal remediation cycle. Failure (<=4/8 or <=7/12) stops
heuristic tuning and requires Founder approval before evaluating an on-device
custom detector.

## Mission

Correctly reconstruct real promotional products from different source types
while minimizing user correction. Do not maximize candidate count.

V0.16 Founder Acceptance failed because the universal OCR-first heuristic
oscillated between V0.15 false positives and V0.16 false negatives. Passing
synthetic regressions did not demonstrate real-world import quality.

## Approved source-adaptive architecture

- Native-text PDF: local native text plus character/fragment bounds, layout-aware
  structured representation, product-cell reconstruction. OCR is not primary.
- Image-only/scanned PDF: existing behavior may remain while the Local Image POC
  is evaluated; render only pages lacking reliable native text.
- Promotional image/screenshot: local preprocessing → multi-signal region
  proposal → independent region crops/OCR → structured representation → product
  reconstruction. Price is a strong but non-exclusive proposal signal and never
  creates a product candidate by itself.
- Retailer adapters: Costco, PX Mart, FamilyMart and generic fallback provide
  merchant/layout/label hints without hard-coded product identities.
- All routes converge into canonical products with per-field evidence, then
  deterministic validation, confidence, review state and final import.

## Founder-approved Hybrid Local-first privacy boundary

Cloud processing is permitted only for a user-selected promotional image or the
minimum scanned PDF pages that need vision. Every transmission requires explicit
per-import consent. No background or silent upload is allowed.

Never transmit stored coupons, reminders, database, history, unrelated files or
unrelated PDF pages. Cloud output is evidence, not truth, and cannot directly
write the coupon database.

The provider must remain replaceable. Production configuration is disabled unless
an HTTPS endpoint, provider identity and complete privacy disclosure are supplied.
No provider API key may be embedded in the APK.

## Cost controls

- 30 MB local import cap; 8 MB cloud asset cap.
- Only pages without reliable native text are cloud-eligible.
- At most one cloud request per selected image or required PDF page per operation.
- Duplicate request keys are rejected; no automatic retry.
- Usage records request count, transmitted bytes, provider failures and configured
  or server-reported estimated cost.

## P0 invariants

1. Non-products independently create zero candidates.
2. One real product region creates exactly one reconstructed object.
3. Product-specific field evidence must equal its product region; only merchant,
   validity period and applicable campaign conditions may cite an explicit shared
   region on the same page.
4. Cross-region ownership failure rejects the object and increments contamination.
5. Missing or low-confidence fields remain unknown/require confirmation.
6. Unit price, average price, threshold, reward points and discount are not silently
   assigned to original/promotional price roles.
7. Native PDF fields retain page, bounds, reading order and cell ownership.
8. Cloud results pass deterministic validation and normal review before atomic save.

linearly with free-user usage must not become a mandatory dependency of the
free/core Clover journey without an approved sustainable revenue model.
