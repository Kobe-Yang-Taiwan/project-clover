# Project Clover Handbook

## 1. Product Mission

幫助使用者管理散落在生活中的優惠與會過期的價值，讓真正擁有的優惠能在正確時間被看見並使用。

## 2. Product Vision

打造一款每天都值得打開的 Life Value OS，讓優惠券、點數、票券與會員權益不再因遺忘而浪費。

## 3. Core Problem

人們不是沒有優惠，而是沒有能力持續管理分散在不同 App、訊息、截圖與紙本中的優惠。

V0.15 Product Discovery 進一步確認：「手動輸入優惠券造成過多操作摩擦。」高候選數不是成功；目標是「一個真實商品＝一個有用候選」。100% 代表永久寫入資料正確，不代表通用 OCR 自動辨識率 100%。Universal Import 同時降低輸入時間與操作次數。

## 4. Target User

第一版聚焦於 25～45 歲、經常替自己或家庭管理優惠券、票券、點數與會員權益的使用者。

## 5. Core Value Proposition

讓使用者在一分鐘內知道：

1. 今天有哪些優惠值得使用。
2. 哪些優惠即將過期。
3. 使用後可以獲得什麼收藏或成長進度。

## 6. Product Principles

1. 幫助使用者減少遺忘，而不是增加資訊。
2. 優惠管理是核心，遊戲化是回訪動機。
3. 每天使用時間應控制在 1～3 分鐘。
4. 第一版優先解決新增、管理、提醒與完成優惠。
5. 不以賭博式機制操控使用者。
6. 每個新功能都必須提升優惠實際使用率，否則暫不開發。

## 7. MVP Core Loop

新增優惠  
→ 查看即將到期項目  
→ 收到提醒  
→ 成功使用優惠  
→ 標記完成  
→ 獲得收藏或成長進度  
→ 下一次再次開啟 App

V0.15 的產品價值鏈為：Universal Import → Correct Coupon Data → Reminder → My Day → Reduced Coupon Waste → Daily Habit → Future Gamification。遊戲化保留為未來策略，本版不實作。

## 8. MVP Success Definition

第一版成功，不以功能數量判斷，而以以下結果判斷：

- 使用者能成功新增優惠。
- 使用者不會錯過設定的到期提醒。
- 使用者可以清楚看到今日最該處理的優惠。
- 使用者完成優惠後願意再次回到 App。
