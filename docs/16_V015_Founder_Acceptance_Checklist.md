# Project Clover V0.15 Founder Acceptance Checklist

版本：`0.15.0（Build 15）`　裝置：________　日期：________

## Supermarket screenshot

- [ ] 同一張截圖產生多個商品，不是單一巨型優惠。
- [ ] 狀態列、導覽與活動標題未成為商品。
- [ ] 一個真實商品恰好一個候選。
- [ ] 標題、品牌、商家、價格、條件與分類附到正確商品。
- [ ] 原價沒有證據時顯示未提供。
- [ ] 問題候選置頂、紅字且預設未勾選。
- [ ] 手動勾選問題候選後，可連續逐筆修正。

## Costco PDF

- [ ] 免責文字與純價格不成為優惠。
- [ ] 同商品沒有碎成多筆；同品牌不同商品沒有誤合併。
- [ ] 商家為 Costco 好市多；品牌維持獨立。
- [ ] 型號、規格、ITEM、優惠價與條件屬於正確商品。
- [ ] 只有原價與優惠價皆可靠時才計算節省金額。
- [ ] 使用者可只選想要的商品，只審核所選問題項目。

## Final gate and safety

- [ ] 關鍵問題未解決時，匯入被阻擋且顯示剩餘筆數。
- [ ] 未按最終確認前，資料庫與提醒均沒有改變。
- [ ] 取消匯入、解析失敗或批次寫入失敗不影響既有優惠。
- [ ] V0.8、V0.9、V0.10、V0.11 與目前支援的後續備份皆可還原。
- [ ] 診斷輸出不含優惠名稱、備註、OCR 原文、圖片或 PDF 內容。
