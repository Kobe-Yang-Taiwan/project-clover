# Project Clover V0.15 PRD — Smart Universal Import

## Scope

圖片、截圖與 PDF 在裝置端轉為結構化候選。解析保留 OCR 座標，依商品區域綁定標題、商家、品牌、型號、規格、ITEM、日期、價格與優惠條件。

## Candidate state

- `READY`：必要資料完整可靠，可預選。
- `NEEDS REVIEW`：疑似有效商品，但關鍵欄位缺漏或不確定；置頂、紅字、不預選。
- `REJECTED`：非商品內容，不在一般候選清單顯示。

## Required behavior

1. 圖片不再假設一張等於一筆。
2. PDF 依商品區域分組，ITEM 與空間價格錨點皆可使用。
3. 純價格、活動標題、頁碼、狀態列、免責文字與單獨 ITEM 不得成為標題。
4. 商家與品牌分欄；文件層商家可安全下傳至商品。
5. 原價未可靠出現時為 `null`；只有原價與優惠價皆可靠且相容時才計算 savings。
6. 問題候選可由使用者手動選取，之後只編輯未解決欄位並逐筆前進。
7. Final Validation Gate 阻擋任何仍有關鍵歧義的選取項目。

## Out of scope

雲端 OCR、外部 AI/LLM、登入、雲端同步、家庭共享、iOS、Wallet、商業平台、遊戲系統、相機、Android Share、QR 與 Barcode。
