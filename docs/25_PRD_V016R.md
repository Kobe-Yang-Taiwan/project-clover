## User flow

Import → automatic source detection → product reconstruction → review exceptions →
select wanted promotions → save → reminder.

## Functional requirements

- Detect reliable native PDF text layers locally and preserve bounds/page order.
- Render only PDF pages that require vision.
- Ask explicit consent before each cloud transmission.
- Continue with local fallback/manual entry when consent is refused.
- Reconstruct multiple products from one image without manual cropping.
- Use local price/text/grid/spatial/retailer signals to propose image regions.
- OCR each proposed product crop independently and preserve region ownership.
- Offer `少了一個商品？點一下圖片中的商品` recovery without normal text entry.
- Make zero cloud calls from the standard promotional-image path.
- Require region and per-field provenance from multimodal output.
- Reject missing evidence and cross-region evidence deterministically.
- Preserve DIRECT_IMPORT / NEEDS_CONFIRMATION / EXCLUDED behavior.
- Display local region count/recovery state; preserve cloud usage reporting for
  dormant optional research paths.
- Use paid Gemini Developer API `gemini-3.6-flash` only through the controlled
  Clover proxy; reject unpaid mode or mismatched provider/model metadata.
- Report input/output/total tokens and token-derived estimated cost.
- Support decimal monetary values without confusing average/unit prices with the
  promotion total.
