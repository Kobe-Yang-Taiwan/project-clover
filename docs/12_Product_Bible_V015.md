# Project Clover Product Bible — V0.15

## 核心承諾

Project Clover 是 Android-first、Local-first 的優惠管理 App。來源圖片、PDF、OCR 原文與產品內容不會上傳。

## 價值鏈

Universal Import  
→ Correct Coupon Data  
→ Reminder  
→ My Day  
→ Reduced Coupon Waste  
→ Daily Habit  
→ Future Gamification

V0.15 只完成 Universal Import 的品質與低摩擦流程。遊戲化仍是核准的未來方向，但本版不實作 Monster、XP、Rewards、Streak 或遊戲經濟。

## 不可退讓原則

1. 不猜原價、日期、商家或衝突價格。
2. 關鍵歧義未解決前，不寫入資料庫、不建立提醒。
3. 匯入取消或失敗，不改變既有優惠。
4. 舊備份可還原；新增欄位採安全預設。
5. 一個真實商品只建立一個候選。
