# Project Clover V0.12 Beta FAQ

## Project Clover 解決什麼問題？

它集中管理你已擁有的優惠，讓你快速看見今天最該使用的優惠，並在到期前提醒。

## 我的優惠資料會上傳嗎？

不會。本版不登入，也沒有雲端同步；優惠主要保存在手機本機。

## Beta Feedback 會傳送哪些資料？

只會預先填入 App 版本、Build 編號、Android 版本與裝置型號。寄出前由你確認，不包含優惠內容。

## 為什麼沒有收到通知？

先確認 Android 通知權限、優惠提醒開關與排程時間。部分品牌的省電設定也可能延遲背景通知。

## 換手機或解除安裝後資料還在嗎？

不一定。請先匯出 JSON 備份並存到 App 外部；解除安裝或清除 App 資料會移除本機資料。

## 可以還原舊版本備份嗎？

可以。本版維持 V0.8、V0.9、V0.10 與 V0.11 備份相容。

## 如何回報問題才有用？

請寫出操作步驟、預期結果、實際結果與是否能重現，再使用 Beta Feedback 附上裝置資訊。不要在信中附上敏感優惠內容。

## 這是 Google Play 正式版嗎？

不是。這是供 Founder 與小規模外部測試使用的 Debug APK，尚未發布到 Google Play。
