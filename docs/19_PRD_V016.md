# PRD — V0.16 Import Accuracy & Reconstruction

## Goal

Users receive correct coupon/product information from images and PDFs with the lowest reasonable manual correction.

## Functional requirements

- Preserve page, bounding box, coordinates and reading order.
- Classify every text block before candidate generation.
- Segment catalog pages into product cells.
- Associate product name, brand, model, specification, ITEM, price and discount only within the owning cell.
- Inherit merchant or validity period only with reliable page-level evidence.
- Reject specification-only, disclaimer, legal, payment, restriction and UI content.
- Surface only uncertain fields for review.
- Keep excluded content inspectable outside the primary list.

## Quality gates

- No known negative fixture creates a visible candidate.
- No known cross-cell contamination or duplicate for one fixture product.
- No fabricated prices or dates.
- Direct Import requires reliable identity, merchant, valid-until and promotional value when applicable.
- Existing reminder, manual entry, storage, backup and prior import flows do not regress.

## Metrics

Candidate Precision, Candidate Recall, Field Accuracy, Duplicate Rate, Cross-cell Contamination Count and Review Burden use labelled data. Confidence is not reported as accuracy.
