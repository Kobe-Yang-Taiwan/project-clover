# Project Clover V0.12 Founder Acceptance Checklist

測試版本：`0.12.0（Build 12）`

測試裝置／Android 版本：________________

測試日期：________________

執行前先備份目前資料。測試完成前保持 Draft PR #1，不合併 `main`。

## Core functions

- [ ] 全新安裝或覆蓋安裝 APK 成功，軟體資訊顯示 `0.12.0（Build 12）`。
- [ ] 新增優惠後，關閉再開啟 App，資料仍存在。
- [ ] 查看、編輯、刪除、標記完成及恢復待使用均正常。
- [ ] 收藏、九種內建分類及批次刪除／完成／恢復均正常。
- [ ] 全域提醒預設只套用到新優惠，既有優惠不變。
- [ ] 過期優惠可依 30 天、90 天、1 年或全部清理，且刪除前顯示筆數並二次確認。
- [ ] 已完成歷史不會被過期清理刪除。
- [ ] 設定中的 `Beta Feedback｜測試回饋` 可開啟 Email App。
- [ ] Email 內容包含 App Version、Build Number、Android Version 與 Device Model。
- [ ] Email 內容不包含優惠名稱、來源、備註或其他優惠資料。

## Notification

- [ ] 第一次需要提醒時，Android 通知權限流程正常；拒絕權限後仍可使用 App。
- [ ] 提前 1、3、7 天及自訂提醒時間均依原行為儲存。
- [ ] 在未來時間建立測試提醒，實際收到通知。
- [ ] 點擊通知後開啟正確的優惠詳情。
- [ ] 編輯提醒後，舊排程被取代。
- [ ] 標記完成及刪除優惠後，不再收到該優惠通知。
- [ ] 恢復待使用後，有效的未來提醒會重新同步。
- [ ] 清理過期優惠後，有效提醒仍存在，已刪除優惠無殘留通知。

## Backup/Restore

- [ ] 匯出 V0.12 JSON 備份成功，摘要筆數正確。
- [ ] 還原前顯示備份時間、待使用與已完成筆數，並要求二次確認。
- [ ] 取消還原時，手機原資料完全不變。
- [ ] V0.8 備份可還原，缺少的新欄位採安全預設值。
- [ ] V0.9 備份可還原，提醒資料正確。
- [ ] V0.10 備份可還原，收藏與分類正確。
- [ ] V0.11 備份可還原，資料與提醒正確。
- [ ] V0.12 備份可還原，資料與提醒正確。
- [ ] 還原失敗時，手機原資料仍保留。

## Dashboard

- [ ] 今天、3 天內、7 天內、已完成與總數均符合實際資料。
- [ ] 下一張即將到期優惠正確，已完成或已過期優惠不會誤列。
- [ ] 新增、編輯、完成、恢復、刪除及還原後，Dashboard 立即重算。

## My Day

- [ ] 開啟 App 後 5 秒內可辨識「今日推薦」。
- [ ] 今天到期、明天到期與本週必用分組正確。
- [ ] 今日推薦優先考慮收藏且尚未過期的優惠。
- [ ] 完成、刪除或還原後，My Day 立即更新。

## Search/Filter/Sort

- [ ] 名稱、來源／品牌與備註搜尋均可即時找到資料。
- [ ] 七種狀態篩選、收藏篩選與九種分類篩選均正確。
- [ ] 五種排序結果正確。
- [ ] 搜尋、篩選、分類、收藏及排序可組合使用。
- [ ] 清除搜尋或篩選後，完整結果恢復。
- [ ] 排序偏好在 App 重啟後仍保留。

## Acceptance result

- [ ] Pass：可交付 3～10 位外部 Beta 使用者。
- [ ] Conditional Pass：僅有已記錄且不阻擋核心驗證的問題。
- [ ] Fail：存在資料遺失、提醒錯誤、無法完成核心流程或 5 秒內無法辨識今日推薦。
