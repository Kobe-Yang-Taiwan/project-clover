# Project Clover V0.16 Release Notes

Version: `0.16.0+16`

V0.16 changes Universal Import from OCR-fragment guessing to spatial product reconstruction. Text is segmented and classified before fields are extracted. Non-products are excluded, product fields remain inside their owning cell, and only explicit catalog validity periods may be inherited.

The review screen selects reliable items by default, keeps uncertain items unselected, highlights only unresolved fields and allows excluded content to be inspected separately.

This release does not claim universal OCR accuracy. It targets 100% correctness of information that passes the Final Validation Gate and is ultimately saved.

No cloud OCR, external AI, login, sync, gamification or unrelated redesign was added.
